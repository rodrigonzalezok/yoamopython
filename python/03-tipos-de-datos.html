Tipos de datos en Python

Entendé int, float, str, bool y None: cómo Python clasifica información y por qué eso impacta directamente en tus análisis.

Tiempo estimado: 75-95 minPrerrequisitos: 01 Qué es Python, 02 InstalaciónBreadcrumb: Python > Lección 03

1) Concepto teórico profundo

Cuando programás, no manejás “valores sueltos”: manejás datos con tipo. El tipo de dato le dice al intérprete cómo guardar un valor en memoria, qué operaciones están permitidas y cómo debería comportarse ese valor al combinarse con otros. Si pensás en finanzas, es parecido a clasificar instrumentos: no tratás un bono igual que una acción, aunque ambos tengan precio. Con los datos pasa igual: no tratás un texto igual que un número, aunque ambos se vean como caracteres en pantalla.

Python tiene tipado dinámico: vos no declarás explícitamente el tipo antes de asignar (como sí pasa en Java o C++), sino que el intérprete infiere el tipo mirando el valor. Si escribís edad = 35, Python crea un objeto entero y hace que edad apunte a ese objeto. Si después hacés edad = "treinta y cinco", la variable ahora apunta a un string. Esta flexibilidad acelera el desarrollo, pero te exige criterio para no mezclar peras con manzanas.

Idea central: una variable en Python no “contiene” un valor rígido; referencia un objeto que tiene tipo.

int representa enteros y, a diferencia de lenguajes con límites fijos de 32 o 64 bits, Python puede crecer dinámicamente según memoria disponible. Esto evita overflows típicos de otros ecosistemas, aunque no evita errores lógicos. También podés escribir enteros en bases distintas: binario (0b1010), octal (0o12), hexadecimal (0xA) y usar separadores legibles (1_000_000).

float representa números con punto decimal en formato IEEE-754. Acá aparece el clásico 0.1 + 0.2 != 0.3. No es un bug de Python: es una limitación de representación binaria de decimales. En contexto bancario o contable, esto importa mucho: un redondeo mal diseñado puede acumular diferencias en miles de transacciones.

Error común: usar float para cálculos de plata “porque total son dos decimales”. Para montos críticos, conviene Decimal del módulo decimal.

str es cadena de texto. Podés usar comillas simples, dobles o triples. Los strings son inmutables: cada transformación crea una nueva cadena. Soporta Unicode nativamente en Python 3, así que nombres como “González”, “Muñoz” o “Ñandú” funcionan sin trucos. También existen escapes como \n (salto), \t (tab), \\ (barra), \" (comilla) y raw strings r"..." útiles para regex y paths.

bool tiene dos valores: True y False. Técnicamente, en Python bool hereda de int (True == 1, False == 0). Además existe la lógica truthy/falsy: 0, 0.0, "", [], {}, set() y None evalúan como falso; casi todo lo demás, verdadero.

Analogía de negocio: en scoring crediticio, no es lo mismo “no informado” que “cero”. None sería “dato ausente”, mientras que 0 es un valor válido. Confundirlos te rompe métricas.

None representa ausencia de valor. No significa cero, ni falso, ni string vacío: significa “no hay dato”. Para compararlo, lo correcto es is None, no == None, porque verificás identidad semántica del singleton.

¿Por qué esto importa? Porque en data analysis gran parte del trabajo es limpiar y tipar datos. Si un campo de ingresos queda como string con “$”, no podés agregar, calcular percentiles ni modelar. Tipar bien es la base de todo pipeline serio.
Tip profesional: al cargar CSV/Excel, validá tipos explícitamente y registrá reglas de conversión. Eso vuelve tus análisis reproducibles y auditables.

En resumen: tipos de datos no es teoría de manual, es control de calidad. Cuando entiendas bien tipos, vas a detectar más rápido errores de origen, castings peligrosos y resultados engañosos. Y eso es exactamente lo que diferencia a un/a analista junior que “hace correr código” de uno/a que genera confianza en negocio.
