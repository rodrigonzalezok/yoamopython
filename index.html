¿Qué podés hacer después?

Cuando completes las 3 rutas, vas a tener el stack técnico que piden el 90% de los puestos de Data Analyst en Argentina y LATAM. Tu camino después de acá:

  • Python básico + intermedio — variables, funciones, módulos, archivos, OOP intro ✓
  • SQL profesional — JOINs, CTEs, Window Functions, DDL/DML ✓
  • pandas + análisis exploratorio — limpieza, transformación, EDA, estadística ✓
  • → Visualización — matplotlib, seaborn, y después Power BI o Tableau
  • → Machine Learning básico — scikit-learn, regresión, clasificación, métricas
  • → Portfolio de proyectos — 3-5 proyectos en GitHub con README y resultados
  • → Entrevistas técnicas — SQL challenges, live coding con pandas, preguntas de negocio
